# TEAMKICK (팀킥)

아마추어 축구팀의 가입 승인, 일정, 참여 투표, 출석, 팀 매칭,
용병 모집, 선수 기록을 관리하는 앱.

## 현재 상태 (2026-09-14)

**이 저장소에는 아직 애플리케이션 소스가 없다.**
개발 기준과 요구사항 문서만 준비되어 있으며, 코드 작업은
원본 소스가 저장소에 들어온 뒤 시작한다. 자세한 내용은 `HANDOFF.md` 참고.

## 문서

| 문서 | 내용 |
|---|---|
| `CLAUDE.md` | 상시 개발 규칙, 문서 읽는 순서, 검증·보고 기준 |
| `HANDOFF.md` | 현재 작업 위치와 다음 세션의 출발점 |
| `TASKS.md` | 작업 목록(T00~T11)과 완료 조건, 상태 |
| `PROJECT_CONTEXT.md` | 확정 제품 요구사항, 결정과 가정 |
| `ARCHITECTURE.md` | 기술 스택, 구조 제약, 실행 환경, 비용 영향 항목 |

새 세션은 `CLAUDE.md` → `HANDOFF.md` → `TASKS.md` 순으로 읽는다.
