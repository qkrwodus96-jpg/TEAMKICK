# 팀킥

축구팀의 승인, 일정, 투표, 매칭과 선수 기록을 관리하는 모바일 웹앱입니다.

## 처음 사용하기

1. ChatGPT로 로그인합니다. 샘플 화면에서 일정을 확인하고 투표·기록을 체험할 수 있습니다.
2. 계정/설정 → 운영자 초기 설정에서 별도 전달된 일회용 코드를 입력합니다.
3. 우리 팀 시작하기 → 팀 등록 신청에서 실제 팀을 만듭니다.
4. 서비스 관리 → 팀 승인을 누르면 신청자가 그 팀의 주장이 됩니다.
5. 경기 만들기로 일정·구장·외부 상대팀을 입력하거나 매칭 모집을 엽니다.
6. 경기 종료 후 완료 처리 → 실제 출석 확정 → 결과 입력·상대 확인 → 골·어시스트 입력 순서로 기록합니다.

첫 배포는 소유자에게만 공개됩니다. 다른 팀을 초대할 때는 사이트 접근 범위도 확대해야 합니다. 사이트 접근과 앱 내부 팀 가입 승인은 별개입니다.

샘플과 실제 저장 상태는 분리됩니다. 휴대폰 공유/메뉴에서 홈 화면에 추가할 수 있습니다. 알림은 앱 내에서 확인합니다. 스토어 앱·휴대폰 푸시는 아직 제공하지 않습니다.

## 개발

- 기존 pnpm lockfile과 Sites 스타터 구성을 유지합니다.
- 검증: node --test tests/core.test.mjs (node:sqlite 지원 Node 필요)
- 타입 검사: node node_modules/typescript/bin/tsc --noEmit
- 스키마 변경: pnpm db:generate 후 SQL 검토.
- 빌드·배포: Sites skill의 실행 프로필 및 기존 Site 재사용 절차를 따릅니다.

운영자 코드 원문·인증 토큰·환경 비밀값은 Git에 넣지 않습니다. .sites-runtime은 임시 도구·테스트용입니다. DB 스키마는 migration으로만 변경합니다.
