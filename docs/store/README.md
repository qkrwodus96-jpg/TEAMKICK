## 5. 앱 액세스(심사용)

로그인해야 쓰는 앱이라 심사자 안내가 필요하다.
- 로그인 화면의 **샘플 팀 둘러보기**로 주요 화면을 계정 없이 볼 수 있다.
- 모든 기능을 보려면 심사용 계정이 필요하다 → **사장님 결정 필요**(이메일 가입을 켜고 심사용 계정 1개를 만들지, 카카오 테스트 계정을 줄지).

## 6. 올리는 순서

1. (사장님, 한 번) GitHub → 저장소 **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `ANDROID_KEY_PASSWORD` · Secret: 32자 이상 무작위 문자열(채팅에 보내지 않기)
2. (Claude) Actions **Android upload key** 실행(`MAKE`) → 키 파일을 main 에 합침 → 업로드 키 지문으로 `/.well-known/assetlinks.json` 추가
3. (Claude) Actions **Android build** 실행(versionCode 1) → Artifacts 의 `.aab`
4. (사장님) Play Console → 앱 만들기 → 위 1~5 입력 → **비공개 테스트** 트랙에 `.aab` 업로드 → 테스터 이메일 15명 추가 → 검토 제출
5. (사장님→Claude) Play Console → **앱 무결성 → 앱 서명**의 "앱 서명 키 인증서 SHA-256"을 알려주기(공개 정보) → Claude 가 assetlinks 에 추가
   (이게 빠지면 앱 위에 주소창이 보인다)
6. 14일 뒤 정식 출시 신청
